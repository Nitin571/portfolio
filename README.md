# Nitin's Personal Portfolio 🚀

Hey! Welcome to the source code of my personal developer portfolio.

I built this website to share my journey as a Computer Science student, highlight my focus on backend development with Java and Spring Boot, and keep a clean, accessible place on the web for my projects and contact details.

---

## 💡 Why I Built It This Way

* **React + Plain CSS:** Instead of reaching for heavy frameworks or Tailwind, I chose standard CSS3 with custom variables. It kept the bundle tiny, loads fast, and gave me complete control over spacing, colors, and layout.
* **Dark & Light Mode:** Built with a clean dark theme by default, plus an instant one-click toggle to light mode, persisted across visits.
* **Direct & Honest:** No corporate buzzwords or AI-generated filler—just a genuine look at what I'm studying, what technologies I work with, and what I build.
* **Formspree Contact:** The message form connects directly to my email through Formspree, backed with instant field validation and a one-click copy button for my email address.

---

## 🛠️ Tech Stack

* **React 18** — Component-driven frontend
* **Vite** — Fast local dev server and build tool
* **Vanilla CSS3** — Custom properties (tokens), CSS Grid, and Flexbox
* **Lucide React** — Minimal monochrome icons

---

## 💻 Running It Locally

If you'd like to check out the project on your own machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Nitin571/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

---

## 📁 How the Code is Organized

* `src/data/portfolioData.js` — All my personal info, skills, and links live here in one clean file.
* `src/components/` — The React components (Navbar, Hero, About, Skills, Projects, Contact, Footer).
* `src/styles/` — Vanilla CSS for each component, plus `global.css` for the theme colors and fonts.
* `public/` — Holds the downloadable `resume.pdf` and custom `favicon.svg`.
